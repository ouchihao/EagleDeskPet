## Demo 决策

- 虚拟货币称为“鹰币”，初始 0；每完整有效工作分钟 +1，上限 999999，保留不足一分钟进度。
- 隐藏和锁屏不暂停养成；离线计薪沿用最多 2 小时并在饥饿耗尽时截断。v1 旧档迁移不追溯此前工资。
- 商店采用本地游戏币，无真实支付；扣款与授予拥有权一起原子保存，失败不消耗余额。
- 桌子与电脑只改变外观；所有基础动作始终免费，新动作重复播放不扣币、不额外发奖。
- 新情绪场景默认关闭；饥饿进入阈值 25、退出阈值 35，低心情进入 25、退出 40；自动场景有冷却和时长上限。
- 猜拳不下注、不消耗资源，宠物先选拳；奖励为少量心情且有冷却，不奖励金币或经验。
- 保留现有 C# / WPF、最高 60 Hz 时间轴及原地脚点，不以全图淡化或翻转代替肢体过渡。

商品、服装与新动作素材必须经过实际预览才能标记交付。素材生成使用内置 imagegen，关键图、提示词和离线插帧工具保留在仓库；失败时不悄悄切到需要付费 API 的后备路径。
