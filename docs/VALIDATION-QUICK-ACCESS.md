## 交互与外观核对

五个 32 DIP 按钮按商店、便签、定时器、主页、荣誉室排列，使用手绘矢量形状与中文工具提示。240 ms 提示文字；140 ms 悬停放大 / 按压过渡；整体 180 ms 显示、420 ms 离开缓冲后 140 ms 淡出。淡出期间返回能够反转，完全隐藏后没有透明点击区域。显示不抢前台焦点，已打开的窗口复用实例。

测试覆盖当前 125% DPI 显示器的四角、宠物 0.8 / 1 / 1.28 三种大小、同进程遮挡窗口、拖动状态、右键菜单、暂停以及关闭清理。快捷栏不随宠物缩小。内部测试使用生产 WPF 视觉树和真实 Popup 坐标，但点击以程序化事件触发，不能代替完整的人工鼠标验证。

栏的位置使用当前装扮**合成中立帧**的 alpha 边界，换装后才重新测量，不逐帧追随导致抖动。解码预览是 320 × 288，验证需归一化回场景坐标；默认 / 卫衣 / 资本家顶部为 84，牛马牛角约 22.8、战神头饰约 60、航天员头盔约 66。不能把默认头顶高度硬套给其他装扮。

README 中的图片是生产控件与原味站姿的静态布局示意，不是用户桌面截图、Live2D 连续录屏或物理帧率证明。
