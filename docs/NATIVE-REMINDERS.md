# Windows 原生提醒

v1.12 预览版将自建定时提醒接入真正的 Windows 通知中心，不是仿制的 WPF 弹窗。不需要账号、GitHub Token 或 AI 服务。

## 开启

1. 将完整程序包放在固定目录，以普通用户运行 `EagleDeskPet.exe`
2. 右键小鹰 →「定时提醒 · 喝水与小事」
3. 勾选「Windows 原生通知」，可独立保留或关闭宠物气泡
4. 点击测试通知；再添加内容、间隔及是否重复

默认原生通知关闭、宠物气泡开启。启用前检查系统能力，不能注册或系统已禁用时给出提示，不假装已启用。首次启用会为当前 EXE 注册本用户的系统通知身份，并在本地数据目录保存鹰图标。自定义数据目录或测试通道下拒绝注册，避免系统冷启动丢失临时环境后误入真实存档。

支持 Windows 10 1809 及更新版本。通知默认静音，正常出现在系统横幅/通知中心；是否显示横幅由 Windows 通知权限、勿扰和锁屏策略决定。**接口接收成功不表示用户看见或读过**。测试按钮也不会创建、完成或暂停业务提醒。

## 提醒规则

- 内容、1–10080 分钟间隔、一次或重复、最多 8 条的既有规则不变
- 原生通知独立于 AI/GitHub 气泡排队；工作、动画或气泡占用不延后原生提交
- 同时到期合并为一条系统通知；点击定位其中第一条，其余仍可在列表查看
- 同一轮先持久化发送预留，再提交系统；崩溃附近无法确定是否送达时标记「结果不确定」，不自动重复发送
- 系统明确失败会记录结果；查看列表不等于暂停，重复提醒按原间隔继续
- 点击只打开当前提醒；已暂停、删除或上一轮的旧通知只显示说明，不恢复或修改旧状态
- 退出期间不运行后台定时器；重新启动合并逾期消息，不补发所有错过的循环

它不是持续响铃闹钟、Windows 后台计划任务或设备唤醒服务。关闭原生开关也不会抹掉通知中心已有消息。

## 数据、升级和排障

提醒明文保存在 `%LOCALAPPDATA%\EagleDeskPet\reminders.json`，v1.12 格式为版本 2。频道设置、截止时间和每轮发送账本同文件原子保存；旧版本 1 自动迁移。升级前先退出并备份数据目录，回退旧版应恢复备份。便签独立保存，提醒不会自动完成便签或改变养成。

开启后提醒正文也进入 Windows 通知中心，可能按系统设置显示在锁屏；不要写入密码或密钥。未上传 AI/GitHub。

没有横幅时，先看提醒列表的到期/提交状态，再通过窗口中的入口检查「Windows 设置 → 系统 → 通知」，同时查看系统通知中心。不要将「已提交」当作「已显示」。不以管理员身份运行；企业策略或勿扰不由桌宠擅自绕过。

通知兼容组件用 EXE 路径生成身份。建议升级后继续使用同一固定安装路径；搬动程序会成为不同身份，旧通知可能指向旧路径。本版不承诺跨任意目录的点击连续性。普通退出不注销通知身份，以便保留通知点击入口。

## 实现与验证边界

当前选择锁定的 MIT 兼容组件 `Microsoft.Toolkit.Uwp.Notifications 7.1.3`，保持现有 WPF 自包含单 EXE 部署；这不是最新 Windows App SDK 路线。相关依赖声明随程序分发。

已验证：确定性调度/迁移/去重/过期点击、隔离 WPF 联调、专用自包含 EXE 的 Windows `Show` 接受和系统 `History` 返回真实通知 XML。

仍待人工验收：可见系统横幅、真正点击后的已有进程跳转和冷启动、不同勿扰/锁屏策略、睡眠恢复、路径升级、真实多显示器 DPI。不能用模拟回调或 API 接受代替上述证据。测试方法见[专用通知测试说明](../tools/NativeReminderSelfTest/README.md)。
