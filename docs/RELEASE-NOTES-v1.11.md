# v1.11 · 打工装备与到点提醒

## 鹰币与成长

- 工资、钱包、支付账本采用两位小数，按实际工作时间逐分结算；小于一分的部分保留到下次，不会因为每秒更新或重启而丢失。
- 电脑、桌子和衣服分别设阶梯价格；电脑与桌子的付费档位逐级翻倍，衣服为 600 / 1,200 / 2,400 / 4,800 / 10,000 鹰币。默认装备仍免费。
- 装备真的改变赚钱、工作经验和饱食 / 心情衰减。商店显示完整属性、同槽位对比，养成面板显示当前实际每分钟收益。
- 等级采用累计二次增长曲线，金银铜荣誉提高门槛；旧版本等级、已购外观和已得徽章不会被收回。完整数表、预期获取周期、收益计算假设见 [数值设计](ECONOMY-v1.11.md)。

生成源图、可复用提示词和机械拆件流程保存在 [EquipmentV2](../DuckDeskPet/Assets/AnimationSources/EquipmentV2/PROMPTS.md)。修改动作源图后必须更新绑定的源文件哈希；不兼容资源会被阻止上架，不会先收费再显示空白。

## 定时提醒

右键 → **定时提醒…**，输入几分钟后提醒、提醒正文，选择一次或重复。提供喝水 / 起身预设；支持暂停、继续、删除和完成后再来一次。最多 8 条，间隔 1–10080 分钟，正文最多 120 字。

提醒单独保存在本机 `reminders.json`，不发给 AI，不需要账号。不会打断动作、工作或未读 AI / GitHub 气泡；同批逾期合并，消息批次至少相隔 30 秒。退出程序不再后台运行、不会唤醒电脑；未暂停的计时仍按真实时间计算，重启后逾期只合并提示一次，不补播一长串历史提醒。暂停某条提醒才会冻结其剩余时间；暂停宠物动作不会停掉提醒。

## 升级注意

先退出旧程序，再启动新版。新版养成存档为版本 3，旧版程序不能读取新版格式；需要回退时，应使用升级前自行保留的存档副本。升级与验收不替换用户的当前进度，自动化测试使用独立临时目录。

60 Hz 是播放器的时间轴和目标更新上限，不代表任意电脑上都已认证物理 60 FPS；首次资源校验、动作预载和系统负载会影响启动或等待时间。
