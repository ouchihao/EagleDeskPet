# 大头鹰记事本 · 图钉便签墙

右键小鹰 → **大头鹰记事本 · 图钉便签墙**。它是独立窗口，不会把所有便签永久铺在桌面上，也不会影响正在办公的小鹰。

![隔离测试便签墙](images/notebook-wall.png)

上图来自测试数据，不包含用户事项或桌面内容。

## 怎么用

- 输入事项，点“钉到墙上”或按 `Ctrl+Enter`；`Enter` 换行，`Ctrl+N` 回到新便签输入框
- 每张便签都有图钉、纸卡、正文和独立操作；点“展开 / 编辑”阅读长内容或修改
- 点“完成”后先保存，再将该便签收起；进入“已完成”可随时恢复到墙上
- “删除”是独立的永久删除操作，需要确认；不想删除就点取消或按 `Escape`
- `Tab` 可访问主要按钮，编辑 / 删除对话层限制焦点在其内部；系统关闭动画时不播放收起动效

最多保存 **256 张（包括已完成）**，每张 **1000 个 UTF-16 字符单位**。中文一般一字占一单位，一些 emoji 占两单位。达到上限时拒绝新增，不自动丢弃旧便签。长内容可展开滚动阅读，窄窗口自动减少列数。

## 保存与隐私

数据在与桌宠相同的数据目录中，使用独立 `notebook.json` 和备份 `notebook.json.bak`。默认目录为 `%LOCALAPPDATA%\EagleDeskPet`；测试或自定义 `EAGLE_PET_DATA_DIR` 时跟随隔离目录。

不写养成存档，不发金币，不自动创建定时器，不上传 AI / GitHub。内容是本地 JSON，不宣称加密；共享电脑或备份时按自己的隐私需要处理。

保存使用临时文件、刷盘和原子替换。保存失败时不假装完成；文件损坏、未知版本、并发修改时保留原文件并提示，不拿空白墙覆盖旧事项。排查或从 `.bak` 恢复前先关闭便签墙，并另存原文件，避免覆盖唯一副本。
