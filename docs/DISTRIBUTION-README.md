# EagleDeskPet · 大头鹰桌宠 v1.12.0-preview.2

适用于 Windows 10 1809 及更新版本的 Windows x64。完整解压到固定目录后运行 `EagleDeskPet.exe`，无需安装 .NET。

- 升级前先从旧程序右键菜单退出，不要同时运行多个版本。
- 右键可打开商店、养成面板、图钉便签墙、定时提醒、荣誉墙和消息设置。
- 本预览版支持本地便签墙和可选 Windows 原生提醒，保留已有装扮和荣誉；猜拳已移除，喂食、摸头、工作等功能继续保留。
- preview.2 移除饱食度，吃饭 +20 心情、不再加经验；心情影响工资，心情为 0 也可持续工作。最便宜付费商品 5,100 鹰币，按默认装备、无互动连续在线工作约七天定标；离线补算仍最多两小时。
- 便签可新增、修改、完成归档和恢复，合计最多 256 条，每条最多 1000 个 UTF-16 字符单位。
- 定时提醒里的 Windows 通知默认关闭，可手动勾选并发送测试通知；宠物气泡独立开关。请以普通用户运行，系统勿扰或权限可能隐藏横幅，提交不代表已读。
- `EagleDeskPet.Mcp.exe` 是可选的 AI 桥接器，请保留在主程序旁，不要直接双击它。
- 首次启动和首次加载新形象需要校验、合成资源，可能稍有等待。
- 本地提醒只在程序运行时展示，不会在退出后后台唤醒电脑。
- 通知默认静音，不是持续响铃闹钟；启用后正文会进入 Windows 通知中心，可能按系统设置显示在锁屏。通知身份与 EXE 路径相关，移动路径后需重新检查通知功能；旧消息可能仍指向旧目录。

真实进度默认保存在 `%LOCALAPPDATA%\EagleDeskPet`，本压缩包不含任何用户存档、账号或密钥。便签、提醒都是本地明文，不上传 AI，请勿记录密码。**养成存档首次升级 v4 时旧金币和未结工资仅清零一次**，原文件另存独立迁移备份；已购商品、装备、等级、粮食和荣誉保留，之后重启不再清零。提醒格式仍为 v2，不清除便签或消息配置。升级前退出旧程序，回退旧版时使用升级前备份，不让旧版读写 v4。

本包默认使用完整的逐帧兼容动画，并不是免配置的 Live2D 发行包。Live2D 需要 Windows WebView2 Runtime、已核验来源的本机 Cubism Core / Framework、完整的六套模型及本机配置；官方 SDK、模型文件和含绝对路径的 `local-runtime.json` 均不在此压缩包内。源码开发环境可按仓库 Live2D 文档准备本地依赖；资源不齐或渲染失败会明确退回相同装备的逐帧动画，不会清空收藏或存档。官方依赖许可未确认前，请勿自行把开发目录里的 SDK 一起转发。

配置完成后按装扮能力选择动画：待机、工作等由 Live2D 表演；已适配原帧的服装在吃饭、哈欠时保留鼓腮和大嘴表情，其他服装继续使用 Live2D 动作。两种画面以同服装的中立姿态交接，原帧动作仍完整播放两秒；不会把换装中的缺图悄悄替换成默认形象或影响办公动作。

本次仅原味形象启用原帧吃饭、哈欠；另外五套服装继续使用已有 Live2D 动作。其他服装的原帧候选仍待衣料与袖口全程验收，不包含在本包中。

发布文件已不再是旧版的五文件结构。请完整保留两个 EXE、`THIRD-PARTY-NOTICES.md`、本说明、`SHA256SUMS.txt`，以及 `Live2DStage` 内的六个运行文件：`index.html`、`stage.css`、`stage.js`、`actions.js`、`bridge.js`、`geometry.js`，共 11 个文件。该目录是本地渲染页面，不含官方运行库或角色模型；不要只复制两个 EXE，也不要把测试文件、本机配置或用户数据混入分发包。

此版本已通过隔离逻辑测试和真实程序联调；专用测试 EXE 已成功提交系统通知并从系统历史读回，但可见横幅、实际点击、退出后点击、勿扰和睡眠场景尚未完成全部人工验收。

`SHA256SUMS.txt` 可用于校验本包文件完整性；它不是代码签名或安全背书。本 Demo 未进行 Windows 代码签名。
