# EagleDeskPet · 大头鹰桌宠 v1.11.0

适用于 Windows x64。完整解压后运行 `EagleDeskPet.exe`，无需安装 .NET。

- 升级前先从旧程序右键菜单退出，不要同时运行多个版本。
- 右键可打开商店、养成面板、定时提醒、荣誉墙和消息设置。
- 本版增加装备属性、两位小数工资、三套新工位与装扮、金丝眼镜和本地定时提醒。
- `EagleDeskPet.Mcp.exe` 是可选的 AI 桥接器，请保留在主程序旁，不要直接双击它。
- 首次启动和首次加载新形象需要校验、合成资源，可能稍有等待。
- 本地提醒只在程序运行时展示，不会在退出后后台唤醒电脑。

真实进度默认保存在 `%LOCALAPPDATA%\EagleDeskPet`，本压缩包不含任何用户存档、账号或密钥。新版会保留旧余额、收藏、等级和已得荣誉；存档升级为版本 3 后，旧程序不能读取新版格式。如需回退，请在升级前自行备份存档目录。

`SHA256SUMS.txt` 可用于校验本包文件完整性；它不是代码签名或安全背书。本 Demo 未进行 Windows 代码签名。
