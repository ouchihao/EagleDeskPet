# EagleDeskPet · 大头鹰桌宠 v1.12.0-preview.1

适用于 Windows 10 1809 及更新版本的 Windows x64。完整解压到固定目录后运行 `EagleDeskPet.exe`，无需安装 .NET。

- 升级前先从旧程序右键菜单退出，不要同时运行多个版本。
- 右键可打开商店、养成面板、图钉便签墙、定时提醒、荣誉墙和消息设置。
- 本预览版新增本地便签墙和可选 Windows 原生提醒，保留现有经济与装扮。Live2D 仍在开发，本包没有新的 Cubism 大头鹰模型。
- 便签可新增、修改、完成归档和恢复，合计最多 256 条，每条最多 1000 个 UTF-16 字符单位。
- 定时提醒里的 Windows 通知默认关闭，可手动勾选并发送测试通知；宠物气泡独立开关。请以普通用户运行，系统勿扰或权限可能隐藏横幅，提交不代表已读。
- `EagleDeskPet.Mcp.exe` 是可选的 AI 桥接器，请保留在主程序旁，不要直接双击它。
- 首次启动和首次加载新形象需要校验、合成资源，可能稍有等待。
- 本地提醒只在程序运行时展示，不会在退出后后台唤醒电脑。
- 通知默认静音，不是持续响铃闹钟；启用后正文会进入 Windows 通知中心，可能按系统设置显示在锁屏。通知身份与 EXE 路径相关，移动路径后需重新检查通知功能；旧消息可能仍指向旧目录。

真实进度默认保存在 `%LOCALAPPDATA%\EagleDeskPet`，本压缩包不含任何用户存档、账号或密钥。便签、提醒都是本地明文，不上传 AI，请勿记录密码。新版保留旧余额、收藏、等级和已得荣誉；养成存档沿用版本 3，提醒文件升级为版本 2。升级前退出程序并备份数据目录，回退旧版时恢复升级前备份，不让旧版读写新格式。

此版本已通过隔离逻辑测试和真实程序联调；专用测试 EXE 已成功提交系统通知并从系统历史读回，但可见横幅、实际点击、退出后点击、勿扰和睡眠场景尚未完成全部人工验收。

`SHA256SUMS.txt` 可用于校验本包文件完整性；它不是代码签名或安全背书。本 Demo 未进行 Windows 代码签名。
