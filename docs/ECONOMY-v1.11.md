# v1.11 · 鹰币、装备属性与成长节奏

这是纯本地养成数值，不接充值、现金或交易市场。目标是第一天就能添一件小装备，中档需要攒几天，资本家套装是数周目标；金章主要面向一至三个月的常规陪伴，而不是连点刷奖。

## 收入与生效规则

- 基础工资仍为 **1.00 鹰币 / 有效工作分钟**，基础工作经验为 1 XP / 分钟。饥饿停工、站立、预览不赚钱。
- 桌子、电脑、衣服的属性相加，不连乘；饱食与心情衰减最多各减免 50%，金币加成最多 +250%，工作经验加成最多 +200%。减免同时作用于工作与休息消耗，不会出现零消耗永动机。
- 只有已拥有且在宿主中真正生效的装备有属性。资源缺失后的默认回退、未拥有项目、商店预览和待生效选择都不提供加成。
- 换装前先按旧装备结算已经过去的区间，新装备只影响后续时间。旧装备积累的半分钟不会被新倍率重新放大。
- 启动先归一化存档，等待资源校验与实际外观就位后才一次性补算离线；加载期间的定时器与互动不会抢先按默认装备结算。失败回退也以渲染器实际使用的装备为准。
- 金额与付款账本使用 `decimal`，余额、商品价格、购买金额显示两位小数；不足 0.01 币的工资保存精确余数，达到一分即入账，不等整分钟，也不按每次计时调用各自四舍五入。
- `WageRemainderUnits` 保存“币 × 秒”的分子；0.60 单位兑换 0.01 币。工作 XP 也保存加权秒余数。随机时间片和重启不会吞掉这些余数。
- 单次离线/长暂停只补算最多两小时，工资 UTC 高水位和有效工作游标阻止回拨重复领钱。钱包上限 999,999.00；达到上限后的时间不会囤成后续收入。
- 支付拒绝三位及更多有效小数；交易编号重复不会再扣款，扣款与所有权一起原子保存。存档写入失败不确认扣款。

## 资本家套装需要多久

计算模型：从零币、默认装备开始；每次攒够价格即购买并生效；不卖旧物、不花币买茶、不计免费薄荷桌；持续补充饱食，使下面的时间都是实际工作的时间。单步有效工时 = `价格 / 当前每分钟工资 / 60`。天数按**每天合计六小时有效工作**换算，不把离线两小时另算在六小时之外。金额实际逐分结算，表中小时保留两位小数。

收益优先路线示例（不是强制购买顺序，也不宣称包含免费解锁后的全局最优解）：

| 新买的项目 | 支出 | 购买前工资 / 分钟 | 本段有效工时 | 累计有效工时 |
| --- | ---: | ---: | ---: | ---: |
| 赛博牛马工作站 | 960.00 | 1.00 | 16.00 h | 16.00 h |
| 闪电电竞桌 | 600.00 | 1.35 | 7.41 h | 23.41 h |
| 摸鱼卫衣 | 600.00 | 1.45 | 6.90 h | 30.30 h |
| 资本家套装 | 10,000.00 | 1.55 | 107.53 h | **137.83 h** |

| 玩法 | 抵达资本家时的有效工作量 | 每日六小时约需 |
| --- | ---: | ---: |
| 不买任何装备，直接攒 10,000.00 | 166.67 h | 27.8 天 |
| 上表收益优先路线 | 137.83 h | 23.0 天 |
| 按下列顺序，每个电脑 / 桌子 / 衣服档位都收藏一件 | 296.83 h | 49.5 天 |

全收藏路线：木鱼电脑 → 薄荷桌 → 水果电脑 → 暖木桌 → 电竞电脑 → 卫衣 → 电竞桌 → 工作站 → 牛马装 → 泡面桌 → 黄金电脑 → 战神装 → 云桌 → 轻薄本 → 董事长桌 → 航天装 → 资本家。总支出 36,010.00，后期替换衣服不叠加旧衣服。Lv.2 免费的茶加上这 17 件付费装备可达到 18 件金收藏章。第一件 120.00 的电脑只要 2 小时基础有效工作，没必要先攒两三天才买东西。

这也说明“总是升级所有低档”并非冲资本家最快的办法：购买价是全价而不是差价，低档属性主要服务早期体验、收藏与个性。饥饿、主动下班、未安装对应资源或消费别的商品都会使日历时间延长；不要求玩家连续工作这么久。

## 等级与荣誉

从 L 级升下一级需要 `100 + 50 × (L−1)` XP；到 L 级的累计 XP 为 `100 × (L−1) + 25 × (L−1) × (L−2)`。例如 Lv.2 / Lv.10 / Lv.25 需要 100 / 2,700 / 16,200 XP，越往后越难。硬上限 Lv.1000，对应 25,024,950 XP；满级显示满进度，不显示无法完成的下一级。

| 荣誉系列 | 铜 / 银 / 金门槛 | 常规节奏下的金章估计 |
| --- | --- | --- |
| 干饭 | 1 / 30 / 180 顿 | 每日 2–3 顿：约 60–90 天 |
| 摸头 | 10 / 150 / 1,200 次 | 每日 15 次：80 天；10–20 次则 60–120 天 |
| 成长 | Lv.2 / Lv.10 / Lv.25 | 上述收益优先路线仅算工作 XP，约 176.24 h、29.4 天；喂养经验会略提早 |
| 工作 | 30 / 1,800 / 18,000 分钟 | 每日六小时：50 天；装备不放大“有效工作分钟”计数 |
| 收藏 | 2 / 9 / 18 件 | 上述逐档全收藏约 49.5 天；默认三件不算 |
| 陪伴 | 25 / 300 / 1,500 次成功照料 | 每日 15 次摸头 + 平均 2.5 顿饭：约 86 天；每日 12–23 次照料约 65–125 天 |

这些是节奏估算，不是领取倒计时。减免饱食使宠物不必频繁喂食，因此也会减慢饭量类计数：最高减免、每天六小时工作且只再补两小时休息时，每天消耗约 40 饱食，长期平均约 1.6 顿饭，180 顿可能需要约 113 天。不会为赶成就强迫过量喂食。低活跃用户可慢慢积累；冷却中连点、饥饿停工不会计数。选择 1,500 而非 2,400 次金陪伴，是因为后者在相同日常频率下约需 137 天，偏离主要目标。

## 旧存档迁移

- 存档升到版本 3，v1/v2 的旧等级一次性映射到新曲线：旧 `level=1+XP/100`，新 XP = 该级新起点 + 旧级内百分比 × 新级所需 XP。整数 XP 向下取整，级内进度误差小于 1 新 XP；**不会掉级**。
- 例如旧 120 XP 为 Lv.2 的 20%，迁移为新 130 XP；旧 900 XP（Lv.10）变为 2,700 XP；旧上限 99,900 XP（Lv.1000）变为 25,024,950 XP。版本 3 重启不会重复映射，也不把这个换算当成新的工作或奖励事件。
- v2 原余额和每笔旧价格的扣款收据原样保留，不补价、不退款；所有已购、未知但合法的内容 ID、待生效选择与已得铜银金荣誉均保留。已拿的金章不会因为新门槛提高而锁回去。
- 旧工资的不足一分钟余数按**原基准倍率**保留；以后实际工作时结算。不会从累计历史工时追发钱。v1 原本没有钱包，迁移不认注入的钱包字段，也不追发迁移前的工资。
- 旧有效满收藏不因新增目录而损坏；没有空位时只阻止新购买，不删除旧收藏。原子存档的备份及多实例冲突保护沿用。

## 可复核的测试边界

`tools/EconomySelfTest` 覆盖随机 100 ns 时间片、多次 JSON 重启、换装前后分段、缺资源回退、未拥有 / 待生效装备、衰减与倍率上限、两小时离线、回拨、分币幂等支付、v1/v2 各等级边界迁移；`ContentSelfTest` 覆盖全收藏和旧满档保留；`HonorSelfTest` 覆盖精确门槛、旧徽章保留及只读展示。收益路线的工时公式也有独立断言。所有持久化测试只使用隔离目录，不读写真实养成数据。
