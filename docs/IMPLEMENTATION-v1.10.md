## 设计约束

- 原生可交互控件负责商品、按钮、文字与布局；AI 插画只做真实嵌入的装饰层，不把概念图当完成的界面。
- 商品使用已有道具 / 衣服图片作图标；不以无关 emoji 冒充商品，不遮挡真实价格和已拥有状态。
- GUI 转场不改变小鹰脚点、演出帧或业务时间线，不用整图翻转 / 淡化跳过角色动作。
- 购买与成就规则不能因翻页、预览、窗口动画、鼠标悬停而写盘或发奖。
- 保留后续 IDEA 池；本轮不加入真实货币、联机、商店轮换或强制签到。
