# 大头鹰 v1.8 · 快速上手

1. 先退出正在运行的旧版。解压 `EagleDeskPet-v1.8.0-win-x64.zip` 后双击 `EagleDeskPet.exe`；源码发布目录为 `dist/v1.8.0`。启动需要预载动作，稍等片刻。不需要安装 .NET。
2. 右键菜单改成奶油色与鼠尾草绿的圆角样式，摸头、喂饭、哈欠、工作等选项直接显示，不再藏在“待机组 / 交互组”子菜单里。平时它仍只站立、打哈欠；单击或右键“摸摸头 · 害羞”让它害羞，按住左键可以拖动。右键“我的饭搭子…”打开养成面板，没有可返回的通知时双击也会打开面板。
3. 点面板“开饭”，或把饭拖到小鹰身上，它会播放干饭动作。摸头、干饭都在当前普通动作完整结束后接着表演，完成后恢复站立。初始 5 份饭，每 5 分钟积累 1 份、最多 99 份；满腹、缺粮或冷却中不会扣粮。
4. 右键“开始工作”，或点面板“开始工作”。预载后桌子滑进来、电脑掉到桌上，然后持续办公；连续工作满 30 分钟转为忙碌中，动画一直循环，不反复站起来。工作每分钟额外 +1 经验，每小时消耗饱食度 12、心情 10。
5. 想下班就点“取消工作”；饱食度到 0 也会自动收工。它会完整做完当前阶段，再收电脑和桌子、恢复站立。工作时要喂饭或摸头，请先取消工作并等它收好工位。
6. 右键或面板的“主动职场骚话”可开关每分钟一句的碎碎念，设置会保存。共有 60 条精简本地句子，轮完再随机；小气泡不带名字栏、靠近鹰头。有 AI 提醒或其他气泡时跳过本次，不抢话、不补播积压消息。
7. 点养成面板里的“荣誉展览馆”，或右键同名入口，打开独立展览窗口。可筛选全部、已获得、待解锁；每张卡片有大头鹰头像徽章、类别标记、进度和解锁条件。Demo 有 3 个系列、各铜银金 3 级，共 9 项，展示不扣粮、不扣经验，也不因反复打开而刷奖励。
8. 想收 GitHub 消息：右键“GitHub 消息…”，点“去 GitHub 创建 Token ↗”，创建带 `notifications` 范围的 **classic Token**，粘贴后“验证并连接”。这是可选账号连接，不是让小鹰收集 GitHub 密码，也不是 OAuth 登录。现有未读先安静收入列表；之后约每分钟检查新动态，小气泡提醒，红点保留未读，点“去看看”打开对应讨论。无需 AI 或 MCP，详细步骤和限制见 [GitHub 消息指南](GITHUB-NOTIFICATIONS.md)。
9. `notifications` 权限本身有通知写入能力，但小鹰只执行 GET 读取；“本地全部看过”不会代你标记 GitHub 已读。Token 使用当前 Windows 用户的 DPAPI 加密保存；本地通知列表是明文，可能含私有标题。不要分享数据目录或把 Token 发给 AI。不需要该功能时，在消息窗口“断开并清除本机消息”。未配置账号不会访问 GitHub。
10. 只想养宠物：不用管 `EagleDeskPet.Mcp.exe`，无需 AI 账号和 API Key。想收 AI 提醒：右键「AI 自动传话 · 一键接入」，选择 Codex、Claude Code 或 CodeBuddy Code，先看路径预览，再点击接入；会备份并添加 MCP + 自动 Stop 提醒，客户端仍需审核信任并开新会话。已有手动接入不会被覆盖或重复注册。[一键接入指南](AI-AUTO-SETUP.md) / [MCP 手动指南](MCP.md)。不要直接双击桥接器。
11. 面板“AI 传话”可选收到提醒后返回的应用；来源名须一致，CodeBuddy Code 的自动接入来源也叫 `CodeBuddy Code`。收到消息后点“去看看”，或双击小鹰打开该来源的应用；不能保证进入精确 AI 会话。GitHub 和 AI 通知都只说话，不改变待机或工作动画。

荣誉条件：

| 系列 | 铜级 | 银级 | 金级 |
| --- | --- | --- | --- |
| 干饭搭子 | 累计 1 顿饭 | 累计 10 顿饭 | 累计 30 顿饭 |
| 摸头交情 | 累计 10 次有效摸头 | 累计 50 次有效摸头 | 累计 100 次有效摸头 |
| 成长足迹 | 2 级 | 5 级 | 10 级 |

已有存档的累计数据和旧成就会沿用。徽章已改为九枚整币单色的金属浮雕：吃饭的饭碗饭勺、摸头的手和爱心、成长的奖杯与台阶直接雕在币面，不再贴彩色鹰头。荣誉墙有悬停和间歇扫光，失焦或关闭后停止，并尊重系统减少动画设置。

工作图已修正桌面与下半身遮挡；桌前挡板遮住脚部，避免断开的脚漂在桌下。忙碌火焰换成实心火芯，普通与凶眼之间通过完整闭眼再睁眼衔接，保留原有入场、循环及退场节奏。

程序不会自动监听其他软件的回复。支持结束事件的客户端，可用一次性 `--notify` 模式接 Hook；其余需要 AI 主动调用通知工具。

养成存档位于 `%LOCALAPPDATA%\EagleDeskPet`。不用复制给同事，每个人有自己的进度。工作状态和时长会保存；重启或长时间挂起最多补算 2 小时，有饱食度则重新进场继续工作，饱食度耗尽就停止，不会在饿到 0 后继续赚工作经验。关闭桌宠不等同于取消工作，想结束这轮工作请先点“取消工作”。

本版已有全身害羞与干饭、持续工作/忙碌场景、等级与 9 项荣誉展览、本地碎碎念、AI 通知和可选 GitHub 通知。菜单不再显示动作分组，内部仍区分待机、互动和持续工作。趴桌哭场景、更多等级解锁动作尚未交付。新增动作由 AI 关键姿势配合光流插帧制作，不是把 GIF 半身图直接贴到桌面。动画按最高 60 Hz 播放，实测帧率受显示器和系统调度影响，并非所有电脑恒定 60 FPS 的保证。

本项目不会强行关闭其他桌宠。请勿把旧版验证记录理解为本轮已完成长期物理屏幕帧率或人工多屏拖动验收。
