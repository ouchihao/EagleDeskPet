# Live2D / 逐帧混合动画 · 本机预览

本轮保留 14 段核心动作和站立，按表演需要选择真实 Cubism Core / Framework 参数动画或原逐帧动画，不把“全部必须使用 Live2D”当作目标。原味大头鹰的吃饭 / 哈欠使用原逐帧，其他动作与站立使用 Live2D；五套服装暂保留全部 Live2D 动作，其夸张动作衣料适配仍未通过完整美术验收。保留原 C# 养成、喂食、工作、装备与通知逻辑和完整 PNG 故障回退，不删除用户已购买的形象。

2026-09-30 范围收敛：按用户决定移除猜拳入口、小窗、玩法与五段专属动作，也从新模型移除手指 / 掌型部件。旧制作图片保留作历史来源但不作为当前运行内容；旧存档及 18 枚养成荣誉不清除。办公表现保持当前已认可版本。用户进一步要求恢复原吃饭鼓腮、哈欠大嘴，并将哭泣改为 T-T；混合显示的验收不能沿用此前纯 Live2D 的通过记录。

## 动画和身体结构

- 原味中立分层合成与 `Assets/mascot-animated-neutral.png` 的 alpha / 可见 RGB 保持零差异；不重画头型、脸长和五官
- 保留胸口软锚和无脖子衔接，隐藏肩根有冗余；上臂在脸后、圆帽前臂在嘴前，不能提升整块肩膀遮住脸
- 上臂和前臂分别拆层，隐藏躯干不保留旧翅膀的弧线或外轮廓；手移开时露出的是真正身体
- 上喙、下喙和口腔是独立部件；运行时连续求参数，而不是给静态表情图做转场
- 张嘴缩短下喙下移，口腔同时按宽高展开并使用暖暗色，修复白缝和分离的嘴；闭嘴关键形状不变
- 哭泣用 T-T 粗横线眼、两道纯色宽泪带和轻抽泣，不加高光或渐变；原生画布上眼线 20×3、泪带约 12×24 像素。眼泪跟随脸部网格而非固定贴纸，160 像素宽桌宠预览也单独检查；眉毛中立 / 负轴与办公、忙碌神态保持原样
- 桌面先遮住身体，再仅补画应在桌面上的前臂；同一帧只计算一次模型，用同一份顶点绘制多个遮挡层
- 杯子、饭碗绑定模型实际手部顶点；满碗与空碗不重叠渐变，避免产生两套碗沿

具体参数和制作命令见 [全身绑定契约](../tools/Live2DArt/FULL-RIG.md)。动作路径在 `DuckDeskPet/Live2DStage/actions.js`，场景从已有 `work-scenes.json` 读取；以后换模型须适配这个语义参数与部件契约，不能直接把任意 CDN 模型当作完整宠物。

## 如何在这台机器运行

先构建主项目，再用 PowerShell 运行：

```powershell
.\tools\prepare-live2d-runtime.ps1
```

该脚本读取本机已经取得的官方 Web SDK 5-r.5 和带来源校验的 Framework，默认选择 `DuckDeskPet/Assets/Live2DSource/FullActions/Model/eagle.model3.json`，生成被 Git 忽略的 `.tool-cache/live2d-runtime/local-runtime.json`。启动仓库内构建的 EXE 后自动发现此配置；放到其他目录的构建可用 `EAGLE_PET_LIVE2D_CONFIG` 指定该配置的绝对路径。

右键菜单可查看当前装扮实际后端：`动画 · Live2D + 原帧吃饭 / 哈欠`、`动画 · Live2D（当前装扮）` 或 `动画 · 逐帧兼容模式`。如果 WebView2、模型或本机 SDK 不可用，明确回退到同一套衣服和工位，不允许画面脱装但仍享受装备加成。某套尚无专用混合帧包不算运行故障，继续用对应 Live2D 动作，不让已认可的办公也倒退为旧帧。临时显式使用旧后端可设 `EAGLE_PET_RENDERER=png`，不改动存档。

这里交付的是**本机开发预览**，不把官方 Core、SDK 或作者工具混入源码和对外程序包。其他电脑的独立分发、SDK 使用条件与 Editor 往返仍按 [工具链记录](LIVE2D-TOOLCHAIN.md) 单独验收；当前本机 SDK 配置不能当成免配置的公开安装包。

## 业务和故障边界

C# 是唯一业务时间轴，每 100 ms 或状态边界向页面发送样本；页面在 `requestAnimationFrame` 中连续插值。普通跨动作参数短接续不替代每个动作自己的抬手、合嘴、落手路径。

混合动作开始前以 120 ms 回到同装扮中立姿态，收到带身份的实际绘制确认后，在同一次 WPF 回调换到原帧；两秒动作完整播放，不整只交叉淡化。结束保留末帧至少两个 WPF 回调，后台模型再次确认中立后交还显示。暂停冻结交接，不提前扣下一份饭。原 PNG 内部原有的相邻帧差异仍保留，端点对齐不等于所有中间帧零变化。

宿主支持专用包 `Assets/HybridActions/manifest.json` 的逐套 `native-raster` / `live2d` 路由，但本次不晋级服装候选。没有专用包时直接读取已有原味帧，其余五套继续 Core，不复制默认衣服冒充换装。原味帧字节不变；作者工具及全帧检查见 [混合帧制作](../tools/Live2DArt/HYBRID-ACTIONS.md)。资本家候选存在腕部蓝衣料污染；卫衣候选发现哈欠 46–51 帧袖口 UV 翻向，作者层另行修正；牛马 / 战神 / 航天员的旧衣片映射在大幅抬手时会破裂。未通过完整服装审片的图不包含在运行资源中，中立像素匹配不能替代动作验收。

末帧在实际绘制后才确认；generation、sequence 和 revision 排除迟到、重复及旧实例消息。未确认末帧不能提前扣下一碗粮、交接场景。超时则切回已准备好的同装备 PNG 后端。暂停冻结模型，隐藏图层不吞拖动、菜单和拖放的原 WPF 输入面。

全部模型、贴图和脚本由本地白名单响应；不加载 CDN、远端脚本或任意角色包代码。预览关闭后取消准备并释放 WebView2，测试只使用新建隔离存档。
