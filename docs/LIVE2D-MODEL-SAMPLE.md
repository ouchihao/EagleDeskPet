# 首个真实 Live2D 大头鹰小样

日期：2026-09-23 · REQ-009 · **制作 / 运行链路已打通，正式迁移未完成**

## 本次解决了什么

继续标准 Live2D，不需要三维建模，也没有把 PNG 整图拉伸包装成 Live2D。这里的制作是二维部件原画、ArtMesh、变形器及参数关键形：同一个模型由官方 Cubism Core 连续求解，再由官方 Framework 绘制。

09-22 因缺少模型、对工具调查不够充分而把制作路线交还用户选择，判断过早。本次自行获取制作工具和官方开发依赖，实际完成分层 PSD → CMO3 / MOC3 → 官方 Core 加载 → WebGL 渲染，不再等待用户先提供模型或安装专业工具。

这是独立开发小样，尚未接入 `PetWindow` 或商店，既有 PNG 后端、存档、工资、装备及通知配置均未改变。不能据此勾选 REQ-009 全部完成。

## 实际迭代，而非只检查参数名称

1. 默认导出：完整黑眼被识别为瞳孔，缺少独立眼白裁剪，不能得到正确眨眼
2. 专用绑定 v2：眼睛开始发生真实形变、双脚固定，但官方截图显示闭眼变成尖心形，视觉不合格
3. 专用绑定 v3：重新写入两只眼睛 0 / 0.5 / 1 三个几何关键形。闭眼约 1.25 像素厚、带轻微弧度，半闭与睁眼保留连续插值，不以透明度消失冒充闭眼

v3 的全闭截图为两条细弧线，半闭仍是压缩的椭圆眼，后续可继续精修。双脚直接挂根层；参数扫描检查脚的真实顶点变化，而不是看整张图是否位置不变。关闭不适合禽类的自动人嘴轮廓和眼球物理。

作者记录中的 `officialRuntimeValidation: pending` 是**导出时**的状态，不由导出工具自我背书；官方结果由独立运行探针另行记录。MOC3 的 SHA256 为 `4d4c5e75dcb4f51f42f85edd2470701ba9c22594be7c381bb2fa5e20268ddd5a`，源 PSD 为 `ec70eb236b23117ef0f9633eb4a5497e46cd2454e02657a55015b24cc86d7fdb`。

最终报告：[完整运行结果](validation/live2d-eagle-20260923.json)、[输入来源与哈希](validation/live2d-eagle-20260923-provenance.json)。8 秒请求窗口实际动画采样 8.157 秒，绘制 490 次、回调间隔均值 16.680 ms、P95 16.800 ms；运行时异常、WebGL 错误和非有限数值均为 0。静态加载成功不够，最终通过还要求实际动画帧、采样时长及鹰的脚 / 眼专项断言。

这些是浏览器 `requestAnimationFrame` 和实际绘制次数，**不是显示器物理 Present FPS**；30 FPS WebM 仅用于观看动作，也不能代替 60 Hz 实屏或长时性能验收。新的模型探针并未重新运行所有生产业务测试，09-22 发布包证据仍是独立历史基线。
