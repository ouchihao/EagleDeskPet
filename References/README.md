# 角色动作参考

开发时使用了 39 个 GIF 作为神态和动作参考。原图及拼图没有明确的再分发授权，**不随 Git 仓库提交**，也不嵌入发布程序。

本机的 `Memes/` 可保存合法取得的原件副本；该目录被 Git 忽略。没有这些原图也可以构建和运行桌宠，原始文件哈希检查会在目录缺失时跳过。

文件信息、帧数和动作分类见 [素材目录](../docs/references/assets-catalog.md)。素材目录只记录制作参考，不表示对应动作都已实现。

重新生成的全身关键姿势、提示词、动画帧和 QA 位于 [DuckDeskPet/Assets](../DuckDeskPet/Assets/)。原 GIF 的方形背景、文字和半身裁切不直接带入桌宠。项目不主张原角色和原表情包的版权，也不据此授予相关素材的商用许可。
