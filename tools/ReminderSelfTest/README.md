# 本地定时提醒测试

从仓库根目录运行：

```powershell
dotnet run --project tools/ReminderSelfTest -c Release
dotnet run --project tools/ReminderIntegrationSelfTest -c Release -- .codex-build/reminder-ui-review
```

第一项验证纯计时器、输入限制、暂停续计、离线合并、持久化、损坏文件保留与多实例冲突。
第二项编译实际 `PetWindow.Reminders.cs`、提醒窗口 XAML 和存储代码，用隔离宿主验证气泡优先级及本地提醒不更改外部消息状态；可渲染实际窗口视觉树，不打开桌面窗口。宿主替换外部通知服务与宠物动作，不代表整应用实机冒烟验证。

两者只在自己创建的唯一临时目录内写入 `reminders.json`，完成后清理；不读取真实用户数据目录、宠物经济存档、AI 配置或凭据。图像证据只能输出到仓库 `.codex-build` 内。

## 产品规则

- 最多 8 条；1–10080 整数分钟；正文 1–120 字。支持一次性或间隔重复。
- 暂停冻结剩余时间并撤销该条尚未弹出的消息；已完成的一次性提醒可手动重新计时。
- 退出后无后台服务、不唤醒电脑；未暂停的 UTC 截止时间继续计算。重启或休眠跨越多个周期时，每条最多积累一次待播，同批合并；重复项从恢复时重新计算下一周期。
- AI / GitHub 的正在显示或已排队消息优先，本地提醒等待气泡空闲，批次最少间隔 30 秒。不更改外部未读标记、双击返回应用目标或当前动画/工作状态。
- 本地提醒不受 AI 通知开关或“暂停动作”影响；单独使用每条提醒的暂停按钮。
- 数据独立保存在应用数据目录的 `reminders.json`（原子替换，保留 `.bak`），不发送给 AI / MCP / 外网。写入失败不确认更改或消费待播；损坏、未知版本、多实例冲突均保留原文件，不用空状态覆盖。
