Generated with the native ImageGen tool on 2026-09-20. Each accepted source is a 4 × 4 chronological pose sheet, not a finished 60 Hz animation. ImageGen draws all poses and clothes; extraction, alpha cleanup, fixed-foot registration and segmented RGB/mask RIFE generate runtime PNGs offline.

References: the default canonical `../../mascot-animated-neutral.png`; accepted default paper/specific action sheets for consistent identity; `../../Outfits/Office/neutral.png` and `../../Outfits/Hoodie/neutral.png` for clothing. Canonical standing PNGs are not replaced. Source PNGs are preserved as returned; generated RGB noise outside visible alpha is not artwork.

The first scissors attempt and a failed alpha-only edit had a brown background and were rejected. The first facepalm switched hands and was rejected. Only the corrected transparent scissors and same-side facepalm are retained here. Rock's tenth source cell incorrectly returned to neutral; each rock `.json` explicitly revisits holding cell 7 instead. The repeated pose is non-adjacent and supports breathing during the readable hold; it is not a repeated output-frame block.

First/last keys use the outfit's exact canonical neutral. The first review caught an overly short 6-frame neutral recovery; final timing reserves 20 frames, while retaining 8-frame finger-formation steps. No sprite flips, body crossfades or runtime scale effects are used.
